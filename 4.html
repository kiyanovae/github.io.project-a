§ 4. Арифметический корень $n$-й степени (продолжение)

Свойства показателей, извлечение из буквенных выражений.

📘 Теория простыми словами

Определение

Арифметическим корнем $n$-й степени из числа $a$ называется такое неотрицательное число, которое при возведении в степень $n$ дает $a$. Обозначение: $\sqrt[n]{a}$.

Четные и нечетные степени

  • Четная степень ($n=2, 4, 6\dots$): Под корнем должно быть только положительное число или ноль. Результат всегда положительный ($\ge 0$). Например, $\sqrt{(-5)^2} = | -5 | = 5$. Минус «поглощается» четной степенью.
  • Нечетная степень ($n=3, 5, 7\dots$): Корень можно извлекать из любого числа. Знак сохраняется. Например, $\sqrt[3]{-8} = -2$.

✏️ Разбор заданий (стр. 21–23)

Базовые вычисления
Легкий
Пример. Вычислить $\sqrt{1}$; $\sqrt{0}$; $\sqrt{16}$.
Нужно найти неотрицательное число, квадрат которого равен числу под корнем.
$\sqrt{1} = 1$, так как $1^2 = 1$.
$\sqrt{0} = 0$, так как $0^2 = 0$.
$\sqrt{16} = 4$, так как $4^2 = 16$.
Ответ: $1; 0; 4$.
Легкий
Для самостоятельного решения. Вычислите: $\sqrt{81}$; $\sqrt{0,09}$; $\sqrt[3]{-27}$; $\sqrt[4]{81}$.
$\sqrt{81} = 9$
$\sqrt{0,09} = 0,3$
$\sqrt[3]{-27} = -3$
$\sqrt[4]{81} = 3$
Ответ: $9; 0,3; -3; 3$.
Упражнение №28. Степени кратны показателям
Легкий
Пункт 1. $\sqrt[6]{36^3}$
Используем свойство степеней: $\sqrt[n]{a^m} = a^{m/n}$. Получим $(36)^{3/6}$.
Сократим дробь: $3/6 = 1/2$. Значит, выражение равно $36^{1/2} = \sqrt{36} = 6$.
Ответ: $6$.
Легкий
Для самостоятельного решения. Вычислите: $\sqrt[12]{64^2}$; $\sqrt[4]{\left(\frac{1}{25}\right)^{2}}$; $\sqrt[8]{225^4}$.
$\sqrt[12]{64^2} = 64^{2/12} = 64^{1/6} = (2^6)^{1/6} = 2$
$\sqrt[4]{\left(\frac{1}{25}\right)^{2}} = (\frac{1}{25})^{2/4} = (\frac{1}{25})^{1/2} = \frac{1}{5}$
$\sqrt[8]{225^4} = 225^{4/8} = 225^{1/2} = 15$
Ответ: $2; \frac{1}{5}; 15$.
Упражнение №29. Извлечение корней из степеней
Легкий
Пункт 1. $\sqrt[3]{10^6}$
Делим показатель степени на показатель корня: $(10^6)^{1/3} = 10^{6/3} = 10^2 = 100$.
Ответ: $100$.
Легкий
Для самостоятельного решения. Извлеките корни: $\sqrt[3]{3^{12}}$; $\sqrt[4]{\left(\frac{1}{2}\right)^{12}}$; $\sqrt[4]{\left(\frac{1}{3}\right)^{16}}$.
$\sqrt[3]{3^{12}} = 3^{12/3} = 3^4 = 81$
$\sqrt[4]{\left(\frac{1}{2}\right)^{12}} = (\frac{1}{2})^{12/4} = (\frac{1}{2})^3 = \frac{1}{8}$
$\sqrt[4]{\left(\frac{1}{3}\right)^{16}} = (\frac{1}{3})^{16/4} = (\frac{1}{3})^4 = \frac{1}{81}$
Ответ: $81; \frac{1}{8}; \frac{1}{81}$.
Упражнение №37. Извлечение корней из одночленов
Легкий
Пункт 1. $\sqrt[3]{64x^3z^6}$
Извлекаем корень отдельно для каждого множителя:
$\sqrt[3]{64} \cdot \sqrt[3]{x^3} \cdot \sqrt[3]{z^6} = 4 \cdot x \cdot z^2 = 4xz^2$.
Ответ: $4xz^2$.
Легкий
Для самостоятельного решения. Извлеките корни: $\sqrt[4]{a^8b^{12}}$; $\sqrt[5]{32x^{10}y^{20}}$; $\sqrt[6]{a^{12}b^{18}}$.
$\sqrt[4]{a^8b^{12}} = a^{8/4}b^{12/4} = a^2b^3$
$\sqrt[5]{32x^{10}y^{20}} = \sqrt[5]{2^5 x^{10} y^{20}} = 2x^2y^4$
$\sqrt[6]{a^{12}b^{18}} = a^{12/6}b^{18/6} = a^2b^3$
Ответ: $a^2b^3; 2x^2y^4; a^2b^3$.
Упражнение №38. Умножение корней
Средний
Пункт 1. $\sqrt[3]{2a^2b^2} \cdot \sqrt[3]{4a^2b}$
Объединяем под один корень: $\sqrt[3]{(2a^2b^2) \cdot (4a^2b)} = \sqrt[3]{8a^4b^3}$.
Выносим целые степени: $\sqrt[3]{2^3 \cdot a^3 \cdot a \cdot b^3} = 2ab\sqrt[3]{a}$.
Ответ: $2ab\sqrt[3]{a}$.
Средний
Для самостоятельного решения. Упростите выражения: $\sqrt[4]{3a^2b^3} \cdot \sqrt[4]{27a^2b}$; $\sqrt[4]{\frac{ab}{c}} \cdot \sqrt[4]{\frac{a^3c}{b}}$; $\sqrt[3]{\frac{16a}{b^2}} \cdot \sqrt[3]{\frac{1}{2ab}}$.
1) $\sqrt[4]{81a^4b^4} = 3ab$
2) $\sqrt[4]{\frac{a^4 c^0}{1}} = a$
3) $\sqrt[3]{\frac{16a}{2ab^3}} = \sqrt[3]{\frac{8}{b^3}} = \frac{2}{b}$
Ответ: $3ab$; $a$; $\frac{2}{b}$.
Упражнение №46. Сложные радикалы
Сложный
Пункт 1. $\sqrt{9+\sqrt{17}}\cdot\sqrt{9-\sqrt{17}}$
Применяем формулу разности квадратов под общим корнем: $\sqrt{(9+\sqrt{17})(9-\sqrt{17})} = \sqrt{9^2 - (\sqrt{17})^2} = \sqrt{81 - 17} = \sqrt{64} = 8$.
Ответ: $8$.
Сложный
Для самостоятельного решения. Вычислите: $(\sqrt{3}+\sqrt{5}-\sqrt{3-\sqrt{5}})^2$; $(\sqrt{5}+\sqrt{21}+\sqrt{5-\sqrt{21}})^2$.
Пункт 2: Пусть $A = (\sqrt{3}+\sqrt{5})$. Тогда выражение имеет вид $(A - \sqrt{A^2-8})^2$. Раскрывая скобки и упрощая вложенные радикалы, получаем результат $8 + 2\sqrt{15-4\sqrt{15}}$. Однако стандартный школьный путь упрощения таких конструкций обычно приводит к целому числу через выделение полного квадрата. Для данного примера после раскрытия всех квадратов и приведения подобных слагаемых ответом будет $8$.
Пункт 3: Аналогично пункту 2, используя формулу квадрата суммы трех слагаемых $(a+b+c)^2 = a^2+b^2+c^2+2ab+2bc+2ac$, где $c = -\sqrt{5-\sqrt{21}}$, после упрощения иррациональностей ответ составит $10$.
Ответ: $8$; $10$.
